# OTUS — отказоустойчивая CMS

Проектная работа по развёртыванию Django CMS на пяти облачных ВМ. Цель — показать балансировку веб-запросов и чтения PostgreSQL, автоматическое переключение записи при отказе primary и восстановление работы после отказа одного узла под нагрузкой.

**Статус** — архитектура и сценарии согласованы, реализация и испытания запланированы.
